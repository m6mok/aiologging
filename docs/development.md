# Development

## Environments and targets

Supported runtime matrix: macOS, Python 3.11–3.15. Makefile uses uv with
one environment per version. quick-test/quick-mypy select 3.15; test-all and
mypy-all fail immediately on a failed version rather than printing success
through a later loop iteration. Library typing uses strict Python 3.11
semantics on every interpreter. Never edit build/dist/htmlcov/egg-info or
virtualenv artifacts as source files.

```sh
make test-all
make mypy-all
make stress-quick             # retained legacy delivery regression smoke
make stress-durable           # equal-durability performance measurements
```

For a focused check use the selected interpreter directly, e.g.:

```sh
.venv-3.14/bin/python -m pytest -o addopts='' tests/durable -q
.venv-3.14/bin/python -m mypy aiologging
```

pytest's default coverage gate stays at 80%, with a terminal report. HTML is
not generated by default. A focused no-coverage run uses `-o addopts=''`.
Full checks should retain `--cov=aiologging --cov-report=term-missing
--cov-fail-under=80` and run both old and new suites.

## Evidence

`tests/durable/` covers actual SQLite transactions, FULL acceptance, independent
primary/fallback ACKs, protected ownership, multiprocess spawn, quota/readonly/
SQLite-full failures, unsupported extra, group commit, record/route checksums,
explicit reassignment, sender/ACK crash boundaries, SIGKILL recovery, callback
recursion, independent recipients, blocked custom workers, cancellation and
ordinary exit without shutdown. Crash tests handshake on stdout at the exact
boundary before killing the subprocess; they do not use timing sleeps to
infer whether an ID had committed.

Comparative tests run the same handler/filter scenarios against the running
stdlib. They exercise factories, custom logger classes (including subclasses
of aiologging.Logger), direct Logger/RootLogger construction, adapter hooks,
hierarchy/shared handler identity, callable/mutating/replacement filters,
repeated handler visits, dictConfig/fileConfig, incremental configuration,
module flags, defaults, source caller fields and recovery without a new log
call. Python-version-specific behaviour is compared with that interpreter.

Historical suites import aiologging.legacy explicitly and remain regressions
for the old internal Async* modules. They are not evidence of durable delivery.
The old TCP StreamWriter test now uses a real StreamWriter over a memory
transport: every test and example is offline. HTTP uses httpx.MockTransport;
construct AsyncClient inside the handler's session_factory, on its library
loop. Never inject a ready-made session from the application's loop.

## CI

CI and release packaging run on macos-latest. Tests cover 3.11–3.15 with mypy,
flake8 and the 80% coverage gate. Examples execute every examples/*.py and
terminate. The legacy stress smoke is retained; the durable benchmark also
checks accepted-ID conservation while producing measurement data. Timing
numbers are never CI thresholds. Packaging still uses normal build/twine.
No package version bump, tag, release, or publish is part of this change.
